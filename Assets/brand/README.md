# 品牌资源（app-assets / brand）

客户端默认品牌兜底资源（`pack://app-assets/brand/...`）。车队可被 `/config/public` 的远程 URL 覆盖（§2.3 白名单规则）。

## 需要放置的文件
- `logo.png` — 车队 logo（占位，建议 256×256 PNG，透明底）
- `login_bg.jpg` — 登录页背景兜底图（建议 1920×1080 JPG，≤10MB）

> 当前为占位说明。构建后若缺少上述文件，品牌图加载失败时回退为纯色/空白（已在代码中容错）。
> 车队部署时把真实 logo/背景放入此目录（或全部走远程 URL），即可换肤。
